## OFS-Save-Editor

# What You Can Edit:
• Money - Set your balance to whatever you want.

• Player Level - Set your level directly. XP is handled automatically.

• Stamina - Set your current stamina value.

• Upgrades - All 13 upgrades organized by Factory, Licenses, and Equipment tabs matching the in-game layout. Max caps enforced per upgrade so you can't accidentally corrupt your save. One-click "Max Everything" or max by category.

• Player Bag - Add, remove, or change item quantities. Weight limit enforced based on your current Backpack upgrade level (Lv0: 50 lbs → Lv4: 100 lbs). Visual weight bar shows how full your bag is.

• Main Storage - Edit warehouse zone contents. Add or remove any item.

• Statistics - View your lifetime stats and daily economy breakdown (read-only).

50+ items fully mapped with in-game icons and searchable by name: all ores, ingots, plates, bars, blocks, refined materials, crafted goods, and digsite finds.

# How To Use:
1. Close Ore Factory Squad completely (Steam Cloud syncs on launch/exit - if the game is running, your edits will be overwritten)

2. Run OFS Save Editor

3. Click to open - the file dialog points directly to your saves folder

4. Make your changes

5. Click Save - the dialog defaults back to the same folder so you can overwrite the original

6. Launch the game

# Save files are located at:
%USERPROFILE%\AppData\LocalLow\threeW\Ore Factory Squad\Saves\

Each save slot is a subfolder (OFS_0001, OFS_0002, etc.) containing a SAVE.GZ file.
Backup your saves before editing:The editor enforces game limits (upgrade max levels, bag weight) to prevent corruption, but always keep a backup just in case. (One is made for you by the application but i doesn't hurt to keep your own)
